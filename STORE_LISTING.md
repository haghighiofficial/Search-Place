Search Place is an advanced, ultra-lightweight Local SEO rank-checking and market research tool engineered by Majid Haghighi. It allows digital marketers, SEO agencies, e-commerce brands, and local business owners to simulate authentic Google Search results from any neighborhood, city, or country worldwide using Google's official UULE (Encoded Location Parameter) protocol—without requiring slow VPNs, paid proxies, or GPS spoofing.

Google SERP (Search Engine Results Page) layouts vary significantly based on user location. Local 3-packs, organic rankings, Google Business profiles, localized featured snippets, and local service ads change across cities and even neighboring municipal districts. 

Search Place solves this friction by generating verified, official Google UULE hashes and country parameters (gl), instructing Google Search to render exact localized search results as if you are physically browsing from that target location.

## 🔒 Chrome Web Store Developer Dashboard: Permission Justifications

When submitting the extension on the **Chrome Web Store Developer Dashboard**, copy and paste the following justifications into the respective fields under the **Privacy** / **Single Purpose** tab:

### 1. Single Purpose Description
```text
The single purpose of Search Place is to generate and execute localized Google searches using Google's official UULE (Encoded Location Parameter) geotargeting parameter and country code for any user-selected city or district worldwide.
```

### 2. Permission: `storage`
```text
The storage permission is used exclusively to save the user's favorite location presets and last-used location preferences locally on their device, allowing seamless 1-click switching without re-typing.
```

### 3. Host Permissions: `nominatim.openstreetmap.org` and `photon.komoot.io`
```text
Used exclusively to query global city and neighborhood autocomplete suggestions in real time as the user types in the search bar, allowing lookup of any district or city worldwide. Zero personal data is collected or transmitted.
```

### 4. Remote Code Declaration
```text
No remote code is used. All JavaScript, HTML, and CSS are completely self-contained within the extension package. Zero external CDNs or remote dependencies are loaded.
```

### 5. Data Usage / User Privacy Declarations
- **Does this extension collect or transmit user data?** `No`.
- **Does this extension use personal information?** `No`.
- **Does this extension transmit any data to external servers?** `No`. All searches are performed directly by opening standard Google Search URLs in the user's browser.
